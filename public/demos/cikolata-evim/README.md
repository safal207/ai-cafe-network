# Çikolata Evim digital menu

An independent demonstration for AI Café Network. The production build copies this folder to the `cikolata-evim/` URL on the existing GitHub Pages site.

The source is the supplied [FineDine café menu](https://qr.finedinemenu.com/cikolata-evim-2/menu/69d0222b0dbc4f83db49c74f) and its [chocolate collection](https://qr.finedinemenu.com/cikolata-evim-2/menu/69d022330dbc4f83db49c97e), captured on 2026-11-18. Their displayed price update date is 2026-01-17. The 271 catalog entries retain original Turkish product names and source descriptions. Prices use integer kuruş. Products with missing prices, variable weights or unverified option prices remain visible and link to the source. Confirm availability with the café.

The site opens on a café landing page. The menu is a separate view, with direct links to products and support for previous menu URLs. The interface supports Turkish, Russian and English. The photo feed shows device-local views, likes and share counts. Views are counted once per tab session when a photo is visible or its details are opened. The basket and liked items are stored on the device. The customer can choose dine-in or takeaway on the landing page or in the basket before showing the Turkish summary to café staff. The site has no payment or order transmission integration. Pair prices are the sum of the two source prices.

The logo is sourced from [Çikolata Evim](https://cikolataevim.com/pages/magazalar). The existing authentic `assets/brand.webp` wordmark is reused in the sticky header, footer, landing hero, editorial stories, feed, product-detail dialog, photo grid and pairings; it remains unmodified on a cream backdrop. Generated alternate logo concepts are excluded from the site. Large editorial and detail images request 592px/960px WebP responsive variants from the original FineDine media source and fall back to the catalog image if the larger variant fails. Smaller thumbnail lists retain their economical sources. No generated food image is substituted for a real catalog product photo. The café interior photograph comes from the [Alles Ofis Çikolata Evim project gallery](https://www.allesofis.com/cikolata-evim/). Catalog photography comes from FineDine and uses CSS color grading. The Grand Rocher Cup campaign image is a generated interpretation of the original menu photograph. The product detail shows the original. Key images are bundled as WebP and remaining source images are lazy loaded from the source image host. Branding and photography belong to their respective owners.

To preview the published folder locally, serve this directory with a static HTTP server, for example `python3 -m http.server 8080`.
